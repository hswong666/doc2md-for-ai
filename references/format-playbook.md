# 换书与版式手册

换书、换语言、抽样失败或修改转换算法时读取。本文区分当前实现与仍需外部处理的能力，不把建议当已实现功能。

## 选路

| 输入/目标 | 当前能力与路线 |
|---|---|
| 单栏文本 PDF，允许裁剪图表脚注 | probe + convert_pdf + check，先试转源页 |
| 多栏或混合单/多栏 PDF | 本转换器拒绝；换支持阅读顺序的解析器 |
| 扫描 PDF | probe 可提示需 OCR；本包不提供 OCR |
| EPUB | probe 用标准库粗扫 HTML 结构；转换另用 markitdown 等工具 |
| DOCX / PPTX / HTML | 本包不探测或转换；选对应外部工具，再用 check 检查 Markdown |
| 表格数据、脚注、版式必须保真 | 使用其他实现；本转换器只提供知识库裁剪模式 |

外部工具转换后的内容也需对照源文。不要把“有语义标签”当作格式必然无损的保证。

## baseline 的含义

| 参数 | 当前如何使用 |
|---|---|
| `body_size` | 必需的正文测量值；脚注几何校验与正文基线 |
| `heading_sizes` | 无书签时与编号联合识别标题；有书签则不回退 |
| `footnote_size` | 非 null 时用作页底字号兜底 |
| `superscript_size` | 非 null 且本页识别到脚注时，去小号数字注号 |
| `chrome_bands` | 已测得页带用于删除；null 表示不启用对应带 |
| `paragraph_gap` | 非 null 时按行间空白和前行收句状态断段 |
| `leading_median` | 输出测量记录；不拿它猜缺失段距 |
| `heading_level_source` | 编号深度或书签层级 |
| `columns` / `text_layer` | 输入支持范围门禁，另逐页守卫可识别的多栏 |
| `table_mode` | 抽样结果；转换器仍检查所选页，防止抽样漏表 |
| `body_tolerance` / `bookmark_anchor` / `page_number` | 探测提示，当前不独立控制转换规则 |
| `footnote_separator_y_ratio` | 抽样统计，仅提示；实际转换每页重新找线并校验 |

`null` 是未知，不是“沿用旧书”“使用默认字号”或“没有脚注”。有些书没有常规行距或标题字号，也应保留正文并报告限制。

baseline 带源文件字节数和页数；转换时核对，明显不同则拒绝。相同字节数和页数不能证明同一文件，使用者仍须确保参数来自本次源文件。

## 清理顺序与保护

probe 先测跨页重复的页带，再排除页带统计正文字号。仅靠顶部短行占用率不足以证明是页眉，不再据此删除变化中的首行。缺失、变化或正文同名页眉可能残留，须抽样。

转换器会把未知页带和所选页未命中的书签写进 `known_limits`。书签本身可能落后于书稿，不能通过“有书签”推断标题已全部恢复。自动 check 通过仍需核对这些声明。

转换时先保护书签命中标题、题注与书目，再清已测页带、计算每页正文底线、删除脚注。正文底线不跨页复用。

书目标题匹配 `References / Further Reading / Works Cited / Bibliography / 参考文献 / 延伸阅读`，可带数字节号。保护持续到下一同级/更高级已识别标题；无层级证据时下个已识别标题退出。保留小字号、URL、方括号编号及跨页续行，不自动重排作者条目。

若书目标题用了别名、缺失或没有识别到后续退出标题，可能漏保护或过度保留。先对照源文修正识别，不扩大字号删除范围。

## 脚注

当前转换器逐页寻找窄横线，要求位于页下部、宽度合理，线下行数与字符量受限，且全为小于正文的字号或页码。下方有保护标题/书目/题注则拒绝切除。

没有可靠分隔线时，仅在 `footnote_size` 非 null 的情况下使用“测得小字号 + 在本页正文底线之下”的规则。小字号位于正文流中时保留；无可靠参数时宁可留注文并声明限制。

上标去除保存原始文本；本页没有脚注时恢复原文。无上标配对能力，不能保证每个小数字都是注号，数学/化学等材料需额外复核。

## 图表与代码

- 图/表题使用 `scripts/captions.py` 的共享规则；支持中英、数字及复合编号。点号和连字符在检查匹配时归一化，图与表始终区分。
- 题注排除过长或以句末标点结尾的行。跨行题注及有句号题注可能漏检；短而无句号的正文可能误检。
- 删除位图 bbox 内的非保护文字；**不凭矩形、短标签比例、无中文句号就删除矢量框或整段**，避免吃掉提示框、英文正文和中文冒号段落。
- pdfplumber 默认框线策略与横线/文本列策略取 bbox。仅横线表先限制在多条平行横线构成的区域，再延伸已对齐的文字列边界。要求多行多列、非空密度和面积校验。
- 不使用全页 text/text 猜表，不从表题向后盲删。不确定的表体保留；文档含 `known_limits`。几何检测仍可能误判，重点检查表后短正文。
- 等宽字体与代码前缀是围栏启发式；比例字体代码、数学式可能无法正确归类。不会因分号、括号多就删段。

## 段落与列表

中文行尾与下行行首都是汉字时直接拼接；其他边界插入空格。英文跨行连字符、首字母下沉仅由 check 提示，不自动改词。

遇新列表符号或简单数字编号断项，缩进续行并入该项；返回起项缩进时结束列表。层级嵌套、标记单独占行和没有缩进的续行可能歧义，需对照项数与引导语。输出使用破折号，原数字编号不保留。

未收句的页末缓冲可接到下一页，但文件/节选结束时一定写出。节选在半段结束是限制，应声明，不能丢段或加造句号。

## 失效模式与回归依据

以下是维护裁剪规则时必须保留的护栏；历史现象用于解释风险，不代表当前每本书都会复现。

| 失效模式 | 会造成什么后果 | 修改时核对的判据 |
|---|---|---|
| 用固定 y 坐标跨页判脚注或页脚 | 正文被截掉，前后残句拼成病句 | 页带必须来自本书测量；脚注底线逐页算，分隔线下还须检查字号和保护内容 |
| 页码混入正文统计 | 正文字号或底线被抬高，真正脚注漏删 | 先排除已识别页带与页码，再统计正文；字号相同不等于正文 |
| 小字号标题被当脚注 | 字号倒挂时标题甚至整节消失 | 先保护书签/编号确认的标题，再做脚注裁剪；对照最小字号标题 |
| 仅按默认框线策略找表 | 只有横线的表漏检，文字按列串入正文 | 横线区域加文字列证据确定 bbox；同时核对表后首段，不以表题盲删 |
| 用 `\w` 宽泛匹配 URL | Python 的 `\w` 包含汉字，中文正文可能被整段删除 | URL 判据须整行匹配、显式限制字符；同时回归正常中文段落与真正 URL |
| 为降低断句率强行并段 | 图内标签粘入正文，数字变好而语义变坏 | 对照源页判断段落边界，保留不确定内容并声明，不以指标达标代替正确性 |

题注的 110 字符上限与句末标点排除，是避免将 `Figure 7 represents ...` 正文吞成题注的保守护栏，不是通用排版定律。放宽上限时，须同时回归长题注与正文负例，不能只验证题注命中率。脚注线的位置、宽度也只是候选几何护栏，必须连同线下内容校验使用。

## 换书抽样清单

1. 读 probe 的 sampling / warnings；抽样未发现不等于全书不存在。多栏检测只覆盖有足够可配对正文行的版式，稀疏或复杂浮动栏仍可能漏检。
2. 对照首个书签前的前言、最小字号标题、书目起止、下一页书目续行和脚注；这些内容最容易被裁剪规则误伤。
3. 对照有横线/无框线表、矢量提示框、表后的首段、图题与正文中的同号图/表引用。
4. 核对列表项数、续行、中文冒号段落、英文分号段落、跨页半句、末页和节选最后一句。
5. 用 check 的标准编号定位问题；检查结果不能检出语法自洽的删文。每次修改后跑 selftest，再复核触发问题的真实源页。

EPUB 探测目前只粗扫 ZIP 内 HTML，不按完整 OPF spine 解析阅读顺序；`profile.spine` 是历史字段名，不能据此承诺顺序已经验证。
